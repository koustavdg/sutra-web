## Controlled mobile lab comparison

Three sequential cold-cache runs per page; independent per-metric medians. Same machine, Lighthouse 13.5.0, Chromium 156 and simulated-mobile settings. Before and after builds were served by the same Python HTTP server implementation on separate localhost ports. The pre-change build was preserved before source edits. No other browser regression suite ran during the final measurements.

Homepage median LCP improved about 28%, and transferred bytes fell about 35%. These controlled local results must not be compared directly with the earlier single-run live-site audit or interpreted as a guaranteed change in rankings, citations or field Core Web Vitals.

### Metrics that did not all improve

- OPDS median LCP increased slightly, from 1.60 to 1.73 seconds, despite a higher performance score and fewer transferred bytes.
- Comparison-hub median TBT was 57 ms versus 0 before; CLS was 0.043 versus 0.035 before. Independent lab metrics vary; do not interpret the report as an across-the-board win.
- The homepage's 3.47-second lab LCP still leaves room for improvement. Real-user performance needs field data and may differ substantially.
- All seven pages scored 100 in Lighthouse accessibility and SEO checks in both builds. This is not a complete accessibility audit or evidence of indexing/ranking gains.

## Repeat the loop

See [measurement instructions](../performance-measurement.md). The command is:

```sh
npm run measure:performance -- --base-url http://127.0.0.1:4173 --label next --out output/performance/next --compare-to output/performance/2026-11-26-after-final/results.json
```

Use a new output directory for each run. Raw JSON, settings, samples and Markdown reports are retained locally under `output/performance/2026-11-26-before/` and `output/performance/2026-11-26-after-final/`; generated reports are ignored by Git. The interrupted preliminary `2026-11-26-after/` run is not part of this comparison.

After approval and deployment, measure live against a live baseline separately. Search Console/Bing exports and matched AI recommendation reruns are still needed to measure discoverability outcomes. No tracking scripts or indexing submissions were added.

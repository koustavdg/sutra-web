# Privacy policy publication snapshots

These Markdown files are verbatim snapshots of the existing public support-repository policies, not newly authored policies. `sources.json` records their origins, retrieval date and hashes. The website build renders both into the initial HTML without contacting GitHub; JavaScript provides platform tabs and retains the existing runtime refresh from the public support repository.

After the upstream policies change, refresh the matching snapshots verbatim and update their hashes and retrieval date before the next site publication. Do not silently rewrite policy wording while updating the site theme or metadata. Both platforms must remain readable without JavaScript or when GitHub is unavailable.

These source files are excluded from the public artifact. Only their rendered policy text is published.
